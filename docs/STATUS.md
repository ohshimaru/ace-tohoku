凡例: **実接続** = 設定すれば実サービスと動く／**デモ** = 架空データ・模擬で動作確認できる／**未実装** = 作っていない（差し替え口のみ等）

## 外部接続

| 項目 | 状態 | 内容 |
|---|---|---|
| データベース（PostgreSQL） | 実接続 | 制約・排他制約・トリガーで二重登録や確定後の改変を防止 |
| LINE Login | 実接続（要設定） | OIDC＋PKCE。チャネル未設定の間は開発環境・デモ環境の「模擬LINE」のみ。メッセージ配信は対象外 |
| メール送信 | 実接続（要設定） | Resend / SMTP。未設定時は送信せず履歴に記録（デモ） |
| ファイル保存 | 実接続（要設定） | Supabase Storage の非公開バケット。未設定時はサーバーのディスク（開発用） |
| AI文章（Claude API） | 実接続（任意） | 行動カードの文章整形のみ。数値・判断はアプリのルール。未設定でもルール文で動作 |
| 銀行 | デモ ＋ CSV | デモ口座（架空取引）と明細CSV取込。**銀行API・口座情報サービスとの自動連携は未実装**（契約と正式な認可方式が必要）。送金機能なし |
| Clean Up | CSV取込 | Clean Up に外部APIがないため、請求書一覧のCSVを取込（読み取りのみ）。支払明細の自動取込は未実装 |
| 電子署名 | 未実装 | 差し替え口（adapters/esign.ts）のみ。現在は送付・締結を人が記録し、締結済みファイルを保存 |
